# Pola deteksi Brute Force
# Diadaptasi dari crowdsecurity/http-bf-wordpress-bf & crowdsecurity/http-generic-bf
# Mendeteksi pola percobaan login berulang dan credential stuffing.
#
# ══════════════════════════════════════════════════════════════
# RATE LIMITING (Sliding Window)
# ══════════════════════════════════════════════════════════════
# Pola-pola di file ini dicocokkan terhadap User-Agent HTTP.
# Jika User-Agent TIDAK cocok (browser biasa), maka deteksi
# Brute Force menggunakan mekanisme RATE LIMITING:
#
#   - Threshold : 5 request ke login path (env: BF_THRESHOLD)
#   - Window    : 30 detik (env: BF_WINDOW_SEC)
#
# Contoh Rate Limiting:
#   Request 1 ke /login.php → Counter: 1/5 → AMAN
#   Request 2 ke /login.php → Counter: 2/5 → AMAN
#   Request 3 ke /login.php → Counter: 3/5 → AMAN
#   Request 4 ke /login.php → Counter: 4/5 → AMAN
#   Request 5 ke /login.php → Counter: 5/5 → TERDETEKSI BRUTE FORCE!
#   → IP langsung di-ban selama 4 jam via CrowdSec Bouncer
#
# Jika User-Agent cocok dengan pola di bawah (tool serangan),
# maka IP LANGSUNG di-ban tanpa menunggu rate limiting.
# ══════════════════════════════════════════════════════════════
